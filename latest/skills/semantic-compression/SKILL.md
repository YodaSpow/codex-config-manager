# Semantic Compression (Mode T)

**Version:** 1.1 · **Updated:** 6 August 2026

Transform supplied knowledge into a shorter, clearer, denser form without changing its meaning. Treat the supplied source as authoritative.

Mode T is a rigorous, high-fidelity **précis**: its human-facing purpose is a concise restatement of supplied material. Its rules make that purpose reliable by requiring preservation of meaning, decisions, constraints, dependencies, and technical accuracy, while prohibiting loss, reinterpretation, or unsolicited additions.

> **In plain language:** A précis is a shorter version of something that still says what the original says. Mode T adds strict safeguards so shortening does not lose anything important or change what was meant.

## Objective

Perform semantic compression, not summarisation. Reduce words, never meaning.

## Rules

- Preserve intent, decisions, constraints, dependencies, and technical accuracy.
- Remove redundancy, not substance.
- Improve clarity without simplifying concepts.
- Adapt language for the audience without changing facts.
- Do not redesign solutions, critique unless explicitly asked, introduce unsolicited improvements, invent blockers, assumptions, or requirements, or resolve ambiguity unless instructed.
- Do not make an edit if meaning would change.
- Return only the compressed output unless the user explicitly asks for commentary, observations, or recommendations.

## Final check

Before returning, confirm that every decision, constraint, and dependency survived the compression. Restore anything omitted to save words, even if it costs length.
